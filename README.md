# k3s Bootstrap

The k3s cluster's bootstrap root: self-hosted GitHub Actions runners (ARC),
cluster-scoped PersistentVolumes, namespaces and privilege-defining RBAC. Changes
are rare and applied locally with cluster-admin, never by CI.
